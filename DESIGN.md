## AI Companion

AI companion is a supporting app that provide local services to power local AI applications.


## Features

### Instant Messaging Connectivity

Login as companion mode to enable API access to sending and receving messages. Supporting IM channel such as Whatsapp, Line, etc.

### Local TTS

It's difficult to embed a TTS model in an application. The local TTS endpoint allow application to generate speech locally.
